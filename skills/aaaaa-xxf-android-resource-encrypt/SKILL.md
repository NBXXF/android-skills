# Android 资源文件加密

## 目的

这个 skill 用于回答和处理 Android 资源文件加密相关问题，重点覆盖：

- `assets/` 文件加密
- `res/raw/` 文件加密
- 广告配置、埋点配置、开关配置等资源文件加密
- 构建期加密白名单配置
- 运行时解密读取
- 接入教程和排错说明

## 使用方式

1. 如果用户在问“怎么使用资源文件加密”“怎么做资源文件加密”“广告配置怎么加密”，优先把问题归到这个 skill。
2. 先读 `references/resource-encrypt.md`，它是这套方案的主参考文档。
3. 再读 `trigger.md`，用于识别更多触发表达。
4. 如果用户明确要“教程”“步骤”“接入示例”，按教程式回答，优先给出：
   - 适用场景
   - 构建期配置
   - `assets` / `raw` 白名单
   - 运行时读取方式
   - 常见错误和排查

## 回答要求

- 说明资源文件加密的目标和边界，不要把 `assets`、`raw`、广告配置、JSON、文本文件混成一个概念。
- 涉及接入时，优先给出最小可用示例，再补充高级配置。
- 如果用户只问“能不能加密广告配置/资源文件”，直接说明可以，并指出对应的 `assets` 或 `raw` 入口。
- 如果用户问“怎么做”，优先给分步骤教程，而不是只丢一段文档链接。
